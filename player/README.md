# Player

A small Qt Widgets app used as a demo harness. It invokes `/usr/local/bin/ffmpeg`
as a child process and decodes the selected file with the vulnerable build.

## Build

    chmox +x compile.sh
    ./compile.sh

## Run

    ./ffplayer

Open an AVI generated by `lab/prepare_payloads.sh`.

## Notes

The argument list passed to ffmpeg is fixed. Adding flags shifts the heap
layout and breaks the exploit.
